# Creators, pros, and codes

Read [the website contract](../royaletools-navigator/references/website.md).

Use `/creators`, `/pros`, or `/creator-codes` according to the user's goal. Search using the visible name, tag, or code control and open the exact matching entry. Ask which person the user means if several results remain plausible.

Directory search covers approved entries, not all Clash Royale players. An absent entry does not prove the person is not a creator or pro. RoyaleTools Creator tiers and PRO labels are site distinctions, not ownership verification or a RoyaleTools login status.

A Creator Code may exist without a linked Player Tag or profile. Read its visible availability state. An `Inactive` code is not an active Store recommendation. Return the exact displayed code and source link, and suggest verifying it in the game before use when appropriate. Do not enter a code in a store, make a purchase, or contact the creator unless the user requests that separate action.

Use the approved profile's visible public links for requested background, keeping profile facts distinct from your recommendation. Do not scrape or reconstruct directory content from RoyaleAPI or an unapproved mirror.
