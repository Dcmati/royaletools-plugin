# Community activities

Read [the website contract](../royaletools-navigator/references/website.md).

- **Clan Discovery, `/clan-discovery`:** inspect currently visible showcased clans and their public join policy, members, score, War trophies, and expiry. A showcase is time-limited and is not proof of player fit or an endorsement. If asked to showcase a clan, prepare the public tag and hand off `Showcase clan` and human verification. Do not resubmit to evade the rolling limits.
- **Balance Changes, `/community/balance-changes`:** open the relevant published update, read each card/form's actual changes, and distinguish a buff, nerf, or mixed rework from community reactions. Older updates remain readable but do not accept new votes. Do not infer game balance from like totals.
- **Tier List, `/community/tier-list`:** for a requested personal tier list, use visible tap/keyboard placement controls when available, or supported drag controls. Keep the user's stated ranking criteria. If the browser cannot edit the board, return the proposed tiers and link so the user can place them. A screenshot/export is complete only when confirmed by the browser.
- **Card Bracket, `/community/card-bracket`:** help the user compare the presented choices or build a personal bracket when requested. Use their criteria; do not change an existing bracket merely to inspect it. Handoff unsupported placement or export controls.
- **Card Toxicity, `/community/card-toxicity`:** read the requested card and current totals with the visible search/filter controls. Results measure visitor opinion. They do not measure competitive win rates or establish that a card is objectively toxic.

Public votes and clan submissions are user choices. Do not cast a vote or submit a showcase merely because the user asks which card/clan is best. Preserve site human verification and write limits. Help the user complete the final action themselves.

Use `/community` for newly added activities and the bundled [site catalog](../royaletools-navigator/references/site-catalog.json) for known destinations. Return the useful comparison or prepared personal ranking with the exact page link.
